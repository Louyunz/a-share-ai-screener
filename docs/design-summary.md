# 设计决策摘要（v2）

## 产品形态
- **AI 对话工作区**：画像、选股、解读、模型优化、版本管理仍在一个对话流完成；外层改为 Professional Financial SaaS 三栏（左侧导航、中间对话、右侧上下文），不改变业务逻辑。
- **AI 主动执行**：AI 输出“回复 + 动作计划”，后端执行动作并生成富卡片。低风险动作（更新画像、确认画像、发起选股、解释结果、运行分析与回测）在用户对话确认后由 AI 直接完成；高影响动作（启用新模型、回滚）必须在聊天里得到用户明确同意。
- **右侧投资上下文**：自动展示画像摘要、AI 活动时间线、当前模型/版本、最近结果；宽屏可收起，窄屏为抽屉，不取代聊天操作。

## AI 建模（本版核心差异）
- AI 不只会“网格调参”：它可以选择 5 种内置模型类型、调整 10 因子权重，或直接生成新的策略打分代码。
- 生成的代码必须通过：长度/语法检查 → AST 白名单（只允许 math/numpy/pandas，禁止文件/网络/系统调用/动态执行/下划线属性）→ 子进程冒烟（10s 超时）→ 全区间回测。
- AI 工作过程按真实步骤流式展示（看表现 → 翻数据 → 出方案 → 改代码 → 安全检查 → 回测 → 对比 → 待审批），不伪造“AI 思考”文本。
- 任何模型变更都生成候选版本，用户同意后才激活；保留 parent 链，聊天一句话即可回滚。

## 技术取舍
- 轻量前后端分离：FastAPI 单进程同时托管静态页面与 API；聊天用 `fetch + ReadableStream` 解析 SSE（POST 不能使用 EventSource）。
- 无构建链、无 CDN、纯 SVG 图表，保证比赛现场一键启动、弱网可演示。
- SQLite 存会话/画像/模型版本/审计；数据缓存优先 parquet，无 pyarrow 自动 CSV。
- 真实模型路径走 OpenAI 兼容接口；`LLM_PROVIDER=fake` 仅为本地测试/演示，不是线上降级方案；AI 不可用时直接报错。

## 合规与边界
- AI 不承诺收益、不荐股、不说“稳赚”；回复有违禁词拦截，解读基于真实回测事实。
- 历史回测与示例数据仅用于技术演示，不构成投资建议。
